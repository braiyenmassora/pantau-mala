# Glosarium pantaumala

Satu istilah = satu makna = satu penulisan.

| Istilah                                    | Makna                                                                         |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| **pantaumala**                             | Nama produk (satu kata, lowercase di UI/meta)                                 |
| **Titik panas**                            | Deteksi anomali suhu oleh satelit; **bukan** kebakaran terkonfirmasi          |
| **Risiko**                                 | Estimasi kategori dari indikator/model; **bukan** peringatan resmi            |
| **Peringatan resmi**                       | Hanya bila bersumber dari instansi (BMKG/BNPB/BPBD) dan nama instansi disebut |
| **Sangat tinggi / Sedang / Rendah**        | Label risiko pin (data API saat ini); jangan pakai "Aman"                     |
| **Belum dinilai**                          | Kategori meta bila data tidak cukup                                           |
| **Kelas FWI**                              | Indeks cuaca kebakaran dari model; terpisah dari warna pin risiko             |
| **24 jam terakhir**                        | Jendela waktu deteksi FIRMS yang ditampilkan                                  |
| **Diperbarui … WIB**                       | Timestamp absolut dengan zona waktu                                           |
| **Terdeteksi / diperkirakan / berpotensi** | Kosakata ketidakpastian wajib                                                 |

## Dilarang di UI

- "terjadi kebakaran di…", "bahaya!", "darurat" (kecuali jalur 112/BPBD)
- "live" / "real-time" tanpa cadence jujur
- "akurat" / "terpercaya" tanpa bukti
- "hotspot" sebagai label pengguna
- Sapaan "Anda" (pakai "kamu")
