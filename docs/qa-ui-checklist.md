# Checklist QA — UI / copy (pasca brief kartu & legenda)

- [ ] Kontras teks sekunder (ink-2) ≥ 4.5:1 di atas surface / surface-muted
- [ ] Tidak ada teks < 12px
- [ ] Tidak ada teks terpotong di kartu gempa / dekat kamu (line-clamp 2 cukup)
- [ ] Chip filter: Semua · N = Sangat tinggi + Sedang + Rendah
- [ ] Legenda satu kartu, collapsible, tidak pernah kosong saat dibuka
- [ ] "Diperbarui …" hanya di footer panel (bukan di peta)
- [ ] Disclaimer di footer kartu legenda peta; legenda terlihat juga saat panel dilipat
- [ ] Legenda risiko: Sangat tinggi · Sedang · Rendah (warna = marker) + "Rendah bukan berarti aman."
- [ ] Warna risiko tidak dipakai untuk brand, tren, atau heatmap
- [ ] Heatmap biru (kepadatan) terpisah dari risiko merah/oranye/hijau
- [ ] Tidak ada kalimat yang terbaca sebagai konfirmasi kebakaran
